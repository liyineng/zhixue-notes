# 智学笔记

源码与更新保存在私有仓库：[liyineng/zhixue-notes](https://github.com/liyineng/zhixue-notes)。

模型可插拔的课程资料学习助手。第一版已经可以本机运行，完成以下闭环：

1. 上传 PDF、PPTX、DOCX、Markdown 或 TXT 资料。
2. 自动解析、分块并建立检索索引。
3. 基于资料提问，返回回答和引用编号。
4. 点击引用编号，在右侧 PDF 中跳到对应页面并高亮相关文本行。
5. 生成章节摘要、复习提纲和常见问题清单。
6. 模型先判断输入是要聊天、检索资料还是总结资料；检索不到时，可以回答通用知识并明确标注来源。

## 笔记本、来源与笔记

- **按课程建笔记本**：左上角选择笔记本，点击 `＋` 新建，`✎` 重命名。默认笔记本可重命名，空笔记本可删除。原来的资料会自动归入“我的课程”。
- **选择问答范围**：资料前的复选框决定问答和复习提纲使用哪些来源。不同笔记本的来源分别检索，空笔记本不会检索其他课程的资料。
- **查找来源**：在“资料来源”输入文件名或原文关键词，点击查找。搜索当前笔记本中的文件名和原文片段，点击结果可查看原文，PDF 可跳页与高亮。DOCX、PPTX、Markdown、TXT 可浏览解析后的文本。
- 搜索结果会显示匹配内容所在的页码，摘要优先展示完整查询词附近的原文，兼容之前导入的跨页片段。
- **移动资料**：文件旁点击“移动”，选择另一个笔记本。文件只保留一份，原来的笔记仍保留保存时的引用快照。
- **保存回答**：点击回答下面的“保存为笔记”，正文与来源引用一起保存。“我的笔记”可以打开、修改、删除，也可新建手写笔记。
- **导出 Markdown**：笔记编辑窗口导出当前笔记，或点击“全部导出”导出当前笔记本的全部笔记。导出包含正文、引用编号、来源名称与引用原文。导出前会保存编辑内容。
- 笔记有未保存修改时，关闭、按 Esc 或从笔记打开引用会先提示确认。刷新页面也会触发浏览器的离开提醒。

**问题、回答与引用会自动保存到当前笔记本**，刷新页面或切换笔记本后会恢复。生成过程中刷新会继续等待结果，服务中断后会保留问题并提示重新提问。“清空对话”仅清空当前笔记本的问答，不删除笔记和资料。历史保存在本机数据库中，当前没有把历史自动作为模型多轮上下文。查找来源针对已导入资料，不包含联网搜索。

每条回答（包括失败记录）下方的“删除本条对话”只删除对应的一组问题和回答。顶部“撤销删除”可按最近删除的顺序逐条恢复，包含图片和引用；每个笔记本最多保留最近 **5 条已删除问答**，刷新或重启后仍可撤销，正常对话数量不限。超出 5 条时永久清理最早的删除记录，图片只在没有其他保留问答使用时清理。生成中的问答暂不能删除。已保存的笔记和课程资料不受影响。“清空对话”会永久清空当前笔记本的所有问答及删除记录，确认框会明确提示无法撤销。

提问时按 **Enter 发送**，按 **Shift+Enter 换行**。中文输入法选词确认不会触发发送，原有 Ctrl/⌘+Enter 也可使用。

## 图片题目与引用颜色

在提问框旁点击“图片”，或直接粘贴截图、拖入图片。每次最多 3 张 PNG、JPG 或 WebP，每张不超过 10 MB。可只发送图片，也可补充文字要求。系统识别题目后，结合当前笔记本中勾选的课程资料解答；图片和识别文字随问题保存在本机，刷新后可查看。

默认使用本机 Tesseract OCR（需安装 `tesseract` 和中文 `chi_sim`、英文 `eng` 语言包）。上传后可展开“题目文字（可校对）”修改识别结果；校对后的文字优先使用。文字题可直接使用，复杂公式、图表或手写题建议配置视觉模型并核对条件。

在“模型设置 → 图片题目识别（可选）”中填写支持图片输入的 OpenAI 兼容模型名。接口地址留空使用问答接口及密钥；独立接口请填写其地址和对应密钥。视觉模型负责识别题目与描述图表，现有问答模型再结合选中资料解答。未配置视觉模型时使用本机 OCR，识别失败会提示校对，不会凭空补全题目。

DeepSeek 官方接口的读图、检索规划与证据筛选请求关闭思考模式。正式解答保留思考模式，并预留至少 8192 tokens 的推理及正文总额度；达到上限时扩大额度重试，保留解题推理。空响应最多重试一次，仍为空或被截断时明确报错。

回答中的每个引用编号使用独立颜色，编号、引用卡片、原文高亮保持一致。同一 PDF 页上的多个引用会一起显示，并附编号；完全重叠的文本行以混合颜色和多个编号标记。点击页上方的编号可切换当前引用。

PDF/PPTX 检索按实际页面组织，兼容早期跨页片段。模型从候选页筛选直接相关的原文摘录，程序逐字验证摘录并保留对应文本行坐标。只展示回答实际使用的引用，未知编号会报错。题图中的主机/设备编号不作为检索重点。回答支持表格、标题、有序步骤、代码块等格式；保存和导出保留 Markdown 原文。

## 启动

在项目目录执行：

```bash
./run.sh
```

然后打开：

```text
http://127.0.0.1:8765
```

首次启动会自动创建 `.venv` 并安装依赖。重复启动会直接使用现有环境。

如果需要改端口：

```bash
PORT=8010 ./run.sh
```

开发时启用热重载：

```bash
DEV=1 ./run.sh
```

## 接入模型

进入页面右上角的“模型设置”填写 OpenAI 兼容接口。

DeepSeek 示例：

```text
接口地址：https://api.deepseek.com/v1
模型名称：deepseek-chat
API Key：你的密钥
```

本地 Ollama 示例：

```text
接口地址：http://127.0.0.1:11434/v1
模型名称：qwen2.5:7b
API Key：留空
```

其他云厂商请按其控制台提供的 OpenAI 兼容地址、模型名和密钥填写。

未配置模型时，系统仍可检索资料并返回相关原文，方便先验证解析和引用链路。

配置模型后，每次提问会先经过一次“检索规划”：

- 模型判断是否需要检索资料。
- 需要检索时，模型会补全和改写检索词，而不是只拿原始问题做字面匹配。
- 回答会区分“资料依据”和“通用知识补充”，资料依据必须附引用编号。

## 支持格式

- PDF
- PPTX
- DOCX
- Markdown
- TXT

扫描版 PDF 需要先做 OCR，否则解析不到文本。

## 当前版本限制

- 检索使用 BM25、模型查询改写与原文证据筛选，尚未接入向量检索。
- PDF 高亮目前是文本行级，不是精确到公式内部符号的字符级。
- 中文 PDF 的公式仍可能受到原文件字体编码影响，后续可接 MinerU 或视觉解析模型。
- 表格解析保持文本顺序，复杂跨页表格需要人工核对。
- 对话记录用于恢复页面，模型当前仍按单次问题与选中资料生成回答。
- 直接关键词检索仍可能漏掉近义表达，尚未接入向量检索。

## 数据与安全

- 上传文件保存在 `data/uploads/`。
- 题目图片保存在 `data/question-images/`；清空对话会同时删除该对话关联的图片。
- 资料索引和模型设置保存在 `data/app.db`。
- `data/`、`.venv/` 和临时构建目录已加入 `.gitignore`。
- API Key 只保存在本机，不会写入 Git 仓库。
- 原始文件、数据库、备份和演示文稿均不纳入源码仓库。使用云端模型时，问题和选中资料片段会发送给配置的接口服务商。
- 配置视觉模型后，题目图片会发送到图片识别接口；使用本机 OCR 时，问答接口接收识别文字。
- 本应用默认仅监听本机地址，尚未实现多用户身份认证，不适合直接对公网开放。

## 验证

```bash
.venv/bin/python -m unittest discover -s tests -v
```

测试使用独立临时数据库，不调用模型接口，不修改个人资料。覆盖旧数据迁移、笔记本范围隔离、资料移动、笔记编辑与带引用导出。

浏览器验收脚本为 `scripts/smoke-workspace.mjs`，需要 Playwright 和 Chromium。可设置 `PLAYWRIGHT_MODULES` 为安装 Playwright 的 `node_modules` 目录，再使用 Node.js 运行。服务地址由 `APP_URL` 指定，默认 `http://127.0.0.1:8765`。脚本使用临时笔记本和确定性的问答响应，结束时清理测试资料。

`scripts/smoke-image-citations.mjs` 验证实际本机 OCR、图片单独提问、识别文字校对、刷新恢复与同页多引用颜色，也使用临时资料和模拟问答响应，不调用外部模型。

`node scripts/test-answer-format.mjs` 验证表格、标题、有序列表、代码与引用的安全渲染。

`scripts/smoke-chat-delete.mjs` 验证单条删除、取消删除、刷新后撤销、失败记录、刚发送的问题以及手机布局，使用临时笔记本和模拟问答，不调用外部模型。

## 项目结构

```text
app/
  main.py          FastAPI 接口与静态页面
  db.py            SQLite 数据层
  parsers.py       PDF/PPTX/DOCX/Markdown 解析
  retrieval.py     BM25 检索
  llm.py           OpenAI 兼容模型调用与提示词
  static/          前端页面、样式和 PDF.js
data/              本地上传文件与数据库
```
