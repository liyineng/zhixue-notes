# 智学笔记

源码与更新保存在公开仓库：[liyineng/zhixue-notes](https://github.com/liyineng/zhixue-notes)。

## 下载发行版

在 [GitHub Releases](https://github.com/liyineng/zhixue-notes/releases/latest) 下载 `zhixue-notes-v0.3.0.zip`。这是干净的程序包，不包含作者的对话、笔记、课程资料、数据库、模型设置或 API 密钥。首次启动创建空白工作区，iCloud 同步默认关闭。

需要先安装 **Python 3.11 或更新版本**；解压后在终端进入文件夹，运行 `bash run.sh`，再打开 `http://127.0.0.1:8765`。首次运行会联网安装依赖，模型接口需自行配置。此 ZIP 包含 Python 程序与网页资源，没有内置 Python，也不是 macOS `.app` 安装包。默认本机 OCR 另需 Tesseract 和中文/英文语言包；也可配置视觉模型。

更新已有安装前，请先备份原来的 `data/`，不要删除或覆盖其中的资料。新用户无需复制任何 `data/` 文件。

模型可插拔的课程资料学习助手。第一版已经可以本机运行，完成以下闭环：

1. 上传 PDF、PPTX、DOCX、Markdown 或 TXT 资料。
2. 自动解析、分块并建立检索索引。
3. 基于资料提问，返回回答和引用编号。
4. 点击引用编号，在右侧 PDF 中跳到对应页面并高亮相关文本行。
5. 生成章节摘要、复习提纲和常见问题清单。
6. 模型先判断输入是要聊天、检索资料还是总结资料；检索不到时，可以回答通用知识并明确标注来源。

## 笔记本、来源与笔记

- **按课程建笔记本**：左上角选择笔记本，点击 `＋` 新建，`✎` 重命名。默认笔记本可重命名，空笔记本可删除。原来的资料会自动归入“我的课程”。
- **选择问答范围**：资料前的复选框决定问答和复习提纲使用哪些来源。不同笔记本的来源分别检索，空笔记本不会检索其他课程的资料。
- **查找来源**：在“资料来源”输入文件名或原文关键词，点击查找。搜索当前笔记本中的文件名和原文片段，点击结果可查看原文，PDF 可跳页与高亮。DOCX、PPTX、Markdown、TXT 可浏览解析后的文本。
- 搜索结果会显示匹配内容所在的页码，摘要优先展示完整查询词附近的原文，兼容之前导入的跨页片段。
- **移动资料**：文件旁点击“移动”，选择另一个笔记本。文件只保留一份，原来的笔记仍保留保存时的引用快照。
- **保存回答**：点击回答下面的“保存为笔记”，正文与来源引用一起保存。“我的笔记”可以打开、修改、删除，也可新建手写笔记。
- **导出 Markdown**：笔记编辑窗口导出当前笔记，或点击“全部导出”导出当前笔记本的全部笔记。导出包含正文、引用编号、来源名称与引用原文。导出前会保存编辑内容。
- 笔记有未保存修改时，关闭、按 Esc 或从笔记打开引用会先提示确认。刷新页面也会触发浏览器的离开提醒。

章节范围支持“第一章”“第1章”“第二讲”“前两章”等表达。优先匹配文件名中的章节编号；在本项目的 L01、L02 等课件中，“第一章”对应 L01《组成与分类》，不代表第一部分或全部勾选来源。指定章节未勾选、无法识别或范围冲突时会提示重新明确范围，不会回退整理全部资料。

复习提纲按来源逐份生成，长文件再按连续页面分批，最后直接合并各份结果，不把所有课件再次压缩成一篇短摘要。每批单独校验引用；已配置模型时，某批没有有效引用会报错，避免把未确认的来源标成完成。回答下方的“逐份来源核对”区分读取页数、实际引用页数和无可用文字的文件；读取过资料不等于每个知识点已完整覆盖。

提问中明确指定课件（如“L04里面有两道题帮我做一下”）时，先限定到已勾选的对应课件。做题请求会优先读取带“题目”或“例题”标记的完整页面，包括已识别的图片题干，避免被普通关键词排名挤掉；也可指定“第28页的题”。未勾选的课件不会被自动加入。

来源勾选按笔记本保存在当前浏览器中，刷新和切换后保持原来的选择，包括全部取消勾选。未勾选来源时仍可普通提问，界面会提示使用通用知识；生成复习提纲需要先选资料。恢复生成只更新待完成的回答，保留阅读位置、展开的引用与输入草稿，临时断线会自动重试。

手机端通过顶部“资料与笔记／问答／原文”切换视图，问答输入框保持在当前屏幕底部。

**问题、回答与引用会自动保存到当前笔记本**，刷新页面或切换笔记本后会恢复。生成过程中刷新会继续等待结果，服务中断后会保留问题并提示重新提问。“清空对话”仅清空当前笔记本的问答，不删除笔记和资料。历史保存在本机数据库中，普通提问会自动携带当前笔记本最近 3 轮有效问答（上下文正文最多 6000 字符，较长内容会截短），帮助理解“它”“再详细一点”等追问；已删除、失败、取消或未完成的问答不会带入。查找来源针对已导入资料，不包含联网搜索。

每条回答（包括失败记录）下方的“删除本条对话”只删除对应的一组问题和回答。顶部“撤销删除”可按最近删除的顺序逐条恢复，包含图片和引用；每个笔记本最多保留最近 **5 条已删除问答**，刷新或重启后仍可撤销，正常对话数量不限。超出 5 条时永久清理最早的删除记录，图片只在没有其他保留问答使用时清理。生成中的问答暂不能删除。已保存的笔记和课程资料不受影响。“清空对话”会永久清空当前笔记本的所有问答及删除记录，确认框会明确提示无法撤销。

提问时按 **Enter 发送**，按 **Shift+Enter 换行**。中文输入法选词确认不会触发发送，原有 Ctrl/⌘+Enter 也可使用。

**引用回答追问**：点击某条回答下的“引用追问”，输入框上方会显示被引用回答的预览；填写更具体的问题后发送，也可点击 `×` 移除引用。该条原问题、回答与原图片题干的识别文字会作为本次追问的明确上下文保存，刷新后可展开查看。显式引用追问优先使用所选回答，不再叠加近期对话。旧回答的引用编号不会直接沿用于新回答，资料检索仍只使用当前勾选来源；已删除、失败或其他笔记本的回答不能新建引用。 普通追问如“引用22的题”或“这里22和42”，会在最近 3 轮问答中查找编号对应的原课件页，重新读取当前勾选来源中的题干；引用编号不会当作页码。点击“引用追问”时优先使用所选回答的编号体系。

**生成状态**：以单行灰色文字显示当前实际执行的状态，随进度逐条替换，不再分块显示步骤或资料列表。包含实际检索词、资料名、候选页码和图片页识别状态；文字过长时省略，悬停可查看完整内容。刷新后继续恢复状态，结束或取消后移除提示。

回答中的 LaTeX 公式（行内、独立公式及表格内公式）在本机渲染，代码块保持原样。数字引用兼容 `[1]` 和 `【1】`，新回答统一保存为 `[1]` 并校验来源；历史回答未保存的来源明确显示“来源缺失”。

**取消生成**：发送后按钮变为“取消生成”，可停止本次问答或复习提纲生成。问题、图片和引用草稿保留，便于修改后重新发送；历史会显示“已取消”，不会被迟到的成功结果覆盖。刷新后若发现仍在生成，也可取消并恢复该问题和图片到输入区。已经完成的回答不会被取消操作删除。

**指定课件整理**：例如“L03 讲了什么，整理一下”，会在当前勾选来源中匹配 L03，按真实页码提供整份课件的文字内容，覆盖开头、中间和结尾，不再从全部课件里抽少数片段。也支持课件标题或同时指定 L03、L04；未勾选的课件不会被纳入。摘要不受问答检索片段数限制，页面会区分整理覆盖的文件/页面数和回答实际引用的数量。

## 图片题目与引用颜色

在提问框旁点击“图片”，或直接粘贴截图、拖入图片。每次最多 3 张 PNG、JPG 或 WebP，每张不超过 10 MB。可只发送图片，也可补充文字要求。系统识别题目后，结合当前笔记本中勾选的课程资料解答；图片和识别文字随问题保存在本机，刷新后可查看。

默认使用本机 Tesseract OCR（需安装 `tesseract` 和中文 `chi_sim`、英文 `eng` 语言包）。上传后可展开“题目文字（可校对）”修改识别结果；校对后的文字优先使用。文字题可直接使用，复杂公式、图表或手写题建议配置视觉模型并核对条件。

在“模型设置 → 图片题目识别（可选）”中填写支持图片输入的 OpenAI 兼容模型名。接口地址留空使用问答接口及密钥；独立接口请填写其地址和对应密钥。视觉模型负责识别题目与描述图表，现有问答模型再结合选中资料解答。未配置视觉模型时使用本机 OCR，识别失败会提示校对，不会凭空补全题目。

DeepSeek 官方接口的读图、检索规划与证据筛选请求关闭思考模式。正式解答保留思考模式，并预留至少 8192 tokens 的推理及正文总额度；达到上限时扩大额度重试，保留解题推理。空响应最多重试一次，仍为空或被截断时明确报错。

回答中的每个引用编号使用独立颜色，编号、引用卡片、原文高亮保持一致。同一 PDF 页上的多个引用会一起显示，并附编号；完全重叠的文本行以混合颜色和多个编号标记。点击页上方的编号可切换当前引用。

PDF/PPTX 检索按实际页面组织，兼容早期跨页片段。模型从候选页筛选直接相关的原文摘录，程序逐字验证摘录并保留对应文本行坐标。只展示回答实际使用的引用，未知编号会报错。题图中的主机/设备编号不作为检索重点。回答支持表格、标题、有序步骤、代码块等格式；保存和导出保留 Markdown 原文。

## 启动

在项目目录执行：

```bash
./run.sh
```

然后打开：

```text
http://127.0.0.1:8765
```

首次启动会自动创建 `.venv` 并安装依赖。重复启动会直接使用现有环境。

如果需要改端口：

```bash
PORT=8010 ./run.sh
```

开发时启用热重载：

```bash
DEV=1 ./run.sh
```

## 接入模型

进入页面右上角的“模型设置”填写 OpenAI 兼容接口。

DeepSeek 示例：

```text
接口地址：https://api.deepseek.com/v1
模型名称：deepseek-chat
API Key：你的密钥
```

本地 Ollama 示例：

```text
接口地址：http://127.0.0.1:11434/v1
模型名称：qwen2.5:7b
API Key：留空
```

其他云厂商请按其控制台提供的 OpenAI 兼容地址、模型名和密钥填写。

未配置模型时，系统仍可检索资料并返回相关原文，方便先验证解析和引用链路。

配置模型后，每次提问会先经过一次“检索规划”：

- 模型判断是否需要检索资料。
- 需要检索时，模型会补全和改写检索词，而不是只拿原始问题做字面匹配。
- 回答会区分“资料依据”和“通用知识补充”，资料依据必须附引用编号。

## 支持格式

- PDF
- PPTX
- DOCX
- Markdown
- TXT

PDF 中缺少可用文字层、以图片为主体的页面会自动补充识别：优先使用已配置的图片识别模型，保留题目、原有解答、公式与图表关系；未配置或调用失败时尝试本机中文/英文 OCR。新导入时自动处理，已导入 PDF 在问答或整理时按当前选中的来源补齐。识别结果缓存为补充片段，保留原文件、原有文本片段、真实页码与图片区域坐标。

引用卡片会标注“图片识别”，点击后仍定位到原 PDF 图片区域。识别失败会明确提示哪些页含未识别图片，不会把它们称为空白或未提供。公式、上下标与图表应对照原图核对。本轮自动识别针对图片主体页面；文字丰富页面中的每张插图、PPTX/DOCX 内嵌图片尚未统一解析。

## 当前版本限制

- 检索使用 BM25、模型查询改写与原文证据筛选，尚未接入向量检索。
- PDF 高亮目前是文本行级，不是精确到公式内部符号的字符级。
- 中文 PDF 的公式仍可能受到原文件字体编码影响，后续可接 MinerU 或视觉解析模型。
- 表格解析保持文本顺序，复杂跨页表格需要人工核对。
- 对话记录用于恢复页面；普通提问按本次问题与选中资料生成回答，引用追问会额外带入明确选中的旧回答，尚未自动携带完整多轮历史。
- 直接关键词检索仍可能漏掉近义表达，尚未接入向量检索。

## iCloud 双向同步

左侧点击“iCloud 同步”，开启后立即合并一次；应用服务运行时每分钟检查，也可随时点击“立即同步”。另一台 Mac 登录相同 Apple 账户、开启 iCloud Drive，在独立安装的新版智学笔记中同样开启同步即可。macOS 的设置见 [Apple 的 iCloud Drive 说明](https://support.apple.com/en-nz/guide/mac-help/mchle5a61431/mac)。

- 同步笔记本、导入资料及解析内容、笔记与引用、已完成或失败的问答、删除记录及题目图片。模型设置、API 密钥和浏览器的来源勾选/草稿各设备独立，不放入同步包。
- 各设备保持自己的本地 SQLite 数据库，**不要把同一份运行中的数据库放进 iCloud 给两台设备共用**。应用通过 `iCloud Drive/智学笔记同步/` 交换不可变的修改清单与按内容校验的附件，自动转换本机路径。
- 不同内容的修改自动合并；同一内容的并发修改保留所有版本，同步面板中选择保留哪个。笔记可“全部保留为笔记”。删除与修改冲突时先保留修改，并显示删除版本供选择；删除笔记本与另一台设备新增内容冲突时保留所属笔记本，避免丢失新增内容。选择删除笔记本/资料版本前需先移出或删除其子内容。
- 删除会传播，旧清单延迟到达不会恢复已删除内容。各设备合并后每个笔记本仍只保留最近 5 条已删除问答供撤销。对话按创建时间排序，晚同步的旧回答不会挤入最新上下文。
- 正在生成回答时暂缓同步；附件未下载完整、清单损坏或目录不可访问时保留本机数据并重试。离线可以照常使用，本机尚未同步的修改会在恢复后合并。关闭同步不会删除本机或 iCloud 内容。
- “本机合并完成”表示读取及写入本机 iCloud 目录完成，**不代表苹果服务器已上传完毕**，实际传输请在 Finder 查看。收到更新时会保留阅读位置；有输入草稿、引用追问或笔记编辑窗口时暂缓刷新界面。
- 首次建立同步元数据、导入其他设备修改及解决冲突前，使用 SQLite 在线备份保存到本机 `data/backups/`，包括 WAL 中的内容。同步状态与应用数据一同提交，失败后可重试。备份与 iCloud 的历史清单/附件暂不自动清理，会随使用占用空间；手动清理前请保留完整备份，并确认所有设备的同步状态。
- 当前提供 Mac 本地应用之间的同步；iCloud Drive 本身不会在 iPhone 上运行这个 FastAPI 应用。同步文件由你的 Apple 账户控制，没有额外设置应用层加密。

## 数据与安全

- 上传文件保存在 `data/uploads/`。
- 题目图片保存在 `data/question-images/`；清空对话会同时删除该对话关联的图片。
- 资料索引和模型设置保存在 `data/app.db`。
- `data/`、`.venv/` 和临时构建目录已加入 `.gitignore`。
- API Key 只保存在本机，不会写入 Git 仓库。
- 原始文件、数据库、备份和演示文稿均不纳入源码仓库。使用云端模型时，问题和选中资料片段会发送给配置的接口服务商。
- 配置视觉模型后，题目图片和需要识别的 PDF 图片页会发送到图片识别接口；使用本机 OCR 时，问答接口接收识别文字。
- 本应用默认仅监听本机地址，尚未实现多用户身份认证，不适合直接对公网开放。

## 验证

发行包通过 `python3 scripts/build-release.py --version 0.3.0` 从指定 Git 提交生成，只包含固定清单中的程序、说明与启动文件，输出到忽略的 `artifacts/releases/`。不会读取或打包本地 `data/`、环境、附件及密钥文件。

```bash
.venv/bin/python -m unittest discover -s tests -v
```

测试使用独立临时数据库，不调用模型接口，不修改个人资料。覆盖旧数据迁移、笔记本范围隔离、资料移动、笔记编辑与带引用导出。

浏览器验收脚本为 `scripts/smoke-workspace.mjs`，需要 Playwright 和 Chromium。可设置 `PLAYWRIGHT_MODULES` 为安装 Playwright 的 `node_modules` 目录，再使用 Node.js 运行。服务地址由 `APP_URL` 指定，默认 `http://127.0.0.1:8765`。脚本使用临时笔记本和确定性的问答响应，结束时清理测试资料。

`scripts/smoke-image-citations.mjs` 验证实际本机 OCR、图片单独提问、识别文字校对、刷新恢复与同页多引用颜色，也使用临时资料和模拟问答响应，不调用外部模型。

`node scripts/test-answer-format.mjs` 验证表格、标题、有序列表、代码与引用的安全渲染。

`scripts/smoke-chat-delete.mjs` 验证单条删除、取消删除、刷新后撤销、失败记录、刚发送的问题以及手机布局，使用临时笔记本和模拟问答，不调用外部模型。

`scripts/smoke-followup-cancel.mjs` 验证引用追问、引用快照恢复、取消生成、取消后的输入/图片/引用保留，以及刷新后取消；使用临时笔记本与模拟模型响应。后端测试另外验证实际生成协程被中断、旧引用隔离和迟到结果保护。

`scripts/smoke-cloud-sync.mjs` 使用模拟同步接口检查开关、冲突选择、全部保留、版本预览安全渲染和手机布局，不向真实 iCloud 写入测试数据。`tests/test_cloud_sync.py` 用独立数据库模拟多台 Mac，覆盖离线合并、并发冲突、删除与撤销、附件校验、未完成下载、发布失败重试及设置隔离。启用真实同步后运行其他会创建临时笔记本的浏览器脚本前，应先暂停同步，防止测试数据进入 iCloud。
